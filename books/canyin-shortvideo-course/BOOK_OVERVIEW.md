## 1. 结构 (Structural)

### 类型

实操手册型方法论课程（面向餐饮/实体店老板与编导的短视频运营标准化工程）

### 一句话主旨

实体店老板做短视频不靠创意靠工程：先锁定「进店理由」（商业定位），再用四类脚本（聊观点/晒过程/教知识/讲故事）的固定结构 × 八大爆款元素批量出选题，以原生、高频、多维的内容把「相信并进店的理由」持续晒给精准本地用户，最终引流变现。

### 骨架 (主要论点及其关系)

1. **为什么能变现**：粉丝经济原理 → 有明确变现产品的普通人（包饺子大哥、防水哥、安窗帘大姨）碾压无产品的专业团队（200 万投资的 A 老板）
2. **晒什么**：商业定位 —— 15 个进店理由（产品/店铺/人三维度，策划时组合 ≥2 个维度），内容是把理由可视化，不是自嗨
3. **怎么说**：内容定位 —— 三有原则（有用处/有兴趣/有共鸣）+ 四种内容表达（教知识涨粉快、晒过程流量大、讲故事立信任、聊观点聚真粉）
4. **选题怎么来**：不是灵感是检索 —— 搭素材库（抖音搜索下拉词/同行评论区/热点宝/巨量算数）× 八大爆款元素（成本/人群/奇葩/最差/反差/怀旧/荷尔蒙/头牌）= 爆款选题；快速出选题六技巧（对立/头牌/颠覆/内幕/推荐/套用延展）
5. **脚本怎么写**：填空不是创作 —— 四类脚本各有固定结构与零件库：聊观点（归纳/对比论证 + 六论据类型）、晒过程（火车节模型 + 期待感六技巧）、教知识（解决/推荐/揭秘/案例引入四型）、讲故事（小有成就/成功案例/平凡英雄 + 经典桥段库）
6. **怎么呈现**：拍剪与自然流 —— 拍摄基础（景别/构图/运镜/打光/置景，拒素背景）→ 剪辑十步工作流（粗剪可发布 → 优质精剪勿花哨）→ 原生感（说人话、不夹不装、不开美颜、少画外音）→ 保护 IP 情绪（编导做场域搭建、提问引导、拍后夸奖，禁止批评/逼背稿/打断）
7. **怎么规模化**：进阶脚本（追根溯源/探寻传统文化/扬我国威/帮助弱者/后记型/超级访问/行业一哥/极限测评）+ 矩阵与团队（从粉丝经济到品牌经济；大哥带小弟培养链；分钱机制因行业而异）+ 编导职业化（简历/作品分析/面试话术）

**论点之间的关系**: 递进链条——变现原理（为什么）→ 定位（晒什么）→ 选题+脚本（怎么说）→ 拍剪呈现（怎么落地）→ 团队与进阶（怎么规模化）。前 4 层是主课，第 5-7 层是进阶与职业化延伸。

### 作者要解决的核心问题

「一个不懂短视频的实体店老板/普通编导，如何用可复制、可自检、不依赖创意天赋的标准化流程，把抖音账号做成进店客源？」

## 2. 解释 (Interpretive)

### 关键术语 (作者本人的用法)

| 术语 | 作者的定义 | 和常识用法的差异 |
|---|---|---|
| 进店理由/成交理由 | 用户选择你而不选同行的具体原因，共 15 个，从产品/店铺/人三维度提取，「最好选择两个维度进行策划」「说XXX好就主要体现什么好」 | 常识说「卖点/差异化」，作者把它做成封闭枚举清单并要求一条内容只主打一个 |
| 三有原则 | 内容被喜爱的三个判据：有用处（教程/推荐）、有兴趣（美好/炫技/恶搞）、有共鸣（情感/励志/吐槽） | 不是泛泛的「好内容」，是选题时的三选一过滤器 |
| 四种内容表达 | 聊观点、晒过程、教知识、讲故事——对应四种心智动作：情绪波动、行动、分析、回忆 | 常识按「赛道/垂类」分内容，作者按「心智动作」分 |
| 八大爆款元素 | 成本的/人群的/奇葩的/最差的/反差的/怀旧的/荷尔蒙的/头牌的——加到普通选题上变成爆款选题 | 不是内容类型，是可叠加的「调料」 |
| 火车节模型 | 晒过程脚本结构：起因(必加钩子)+关键步骤+转场+经过+转场+…+结果，一节一节像火车车厢 | 「火车节」是作者自造比喻 |
| 桥段 | 讲故事的预制单元：一轮困境（盲目自信/家门不幸/天灾人祸）、一轮转机（通关密码/至亲寄托/贵人相助/天赋异禀/意外之喜）、二轮困境（恶霸欺压/过河拆桥/至亲背叛/强权干涉）、二轮转机（因祸得福/贵人相助/破釜沉舟） | 借自编剧理论但做成了固定枚举库，可「识别→重新排列组合」 |
| 期待感 | 晒过程的核心引擎，六技巧：金钱/对抗/送温暖/验证揭秘/盲盒/荷尔蒙 | 不是氛围词，是可勾选的钩子类型清单 |
| 原生 | 内容生产要求：越自然越好、说人话、不夹不装、不开美颜、不用花哨分镜、少用画外音 | 与「精雕细琢」的影视化直觉相反 |
| 质检员还是销售员 | 晒过程自检：讲述者应是中立展示过程的「质检员」，不是推销的「销售员」 | 用角色隐喻做语气自检 |
| 情绪曲线 | 讲故事核心：困境与转机两轮交替，二轮痛点/爽点必须高于一轮 | 量化了「故事要好看」 |
| 矩阵 | 多账号布局的意义是「从粉丝经济到品牌经济的过渡」，不是多赚点钱 | 强调品牌资产而非短期收益 |
| 大哥带小弟 | 团队培养机制：任何岗位最后一步都是带出自己的「小弟」，大哥定期关怀小弟的生活 | 用人情结构替代 KPI 管理结构 |
| 拆片 | 用万能表逆向拆解爆款视频：内容类型/脚本结构/拍摄角度/出镜人物/呈现形式/出场方式/剪辑方式 | 学习手段而非抄袭 |

### 核心命题 (用自己的话)

1. 做IP是标准化工程不是创意玄学——「天下没有一个人做不成IP」，像做包子一样有配方
2. 变现的起点是商业定位不是内容：先想清楚用户为什么进店，内容只是把理由演出来
3. 有明确变现产品的素人 > 没有产品的专业团队（「200 万在短视频行业里根本不叫钱」）
4. 四类内容各司其职：教知识展示专业度涨粉快、晒过程眼见为实流量大、讲故事了解自己建立信任、聊观点拉近关系聚真粉
5. 选题 = 素材库检索 × 爆款元素叠加，是排列组合不是灵感
6. 脚本是填空题：每类脚本有结构、有零件库（桥段/论据/钩子），照着创作路径七步走
7. 原生感大于精致感：观众信「该干啥干啥」的记录，不信表演
8. 期待感是留人的引擎：起因必加钩子，经过 1-3 个（不超 3），多个经过服务同一个钩子
9. 一条内容只主打一个进店理由，进店理由贯穿选题而非贴标签
10. 发布前过七问自检（有效/关联/趣味/行动成本低/频次高/可延伸/能落地）
11. IP 是人不是号：编导的职责是保护和放大老板的表达欲，情绪破坏是拍摄大忌
12. AI（DeepSeek 等）可以加速出选题和写文案，但公式得先在脑子里（课程直接给了让 AI 出观点选题/写脚本的具体 prompt 句式）

### 论证链

用大量亲历案例做归纳论证：自己学员（bcd 四选项）、自己的公司实践（红人星球矩阵、老师分工、分钱机制）、课堂现场拆片（帮助弱者视频、追根溯源视频、面诊直播双视频对比）。论证方式是「案例 → 提炼公式 → 课堂演示填空 → 学员当场练习」，几乎不做数据统计论证——这是典型的实操派授课逻辑。

## 3. 批判 (Critical) ★

### 作者的时代局限
- 方法论绑定抖音自然流红利期（2020–2024 打法），对付费流量占比上升、本地生活竞争红海化之后的适配性未验证
- 「荷尔蒙的」爆款元素（黑丝/大胸/搭讪等）在当前平台治理下已是高危擦边项，课程自己也在文档中标注「是否保留进最终餐饮 Skill 需另行确定边界」
- ASR 转写质量参差：机构名在稿中转成「封神星球/华人星球/红人星球/空中星球」多个版本，部分术语（情绪波点、置身事外、倒打一耙的准确含义）存在歧义，文档中已标注「待确认」

### 作者的立场盲点
- 讲者是卖课机构创始人，有过度承诺倾向（「天下没有一个人做不成IP」）
- 幸存者偏差：课堂上展示的都是做起来的案例，做死的学员不上台；「一天买 1300 斤肉馅」这类案例无法证伪
- 立场偏向「内容万能」：把进店率、转化率几乎全归因于内容质量，弱化产品力、选址、价格、服务体验对餐饮成败的权重

### 未被证明的假设
- 「进店理由→内容→到店转化」因果链足够强：未讨论品类差异（高客单低频 vs 低客单高频）、本地流量天花板、餐饮毛利对内容成本的承受力
- 假设自然流量红利持续存在、假设同赛道同行不会同样工业化生产内容
- 「二轮爽点高于一轮」等编剧经验命题无对照验证

### 最强反对意见

这套方法论本质是「工业化套路流水线」。当千百个学员同时使用同一套八大元素 + 同一个桥段库 + 同一套脚本结构时，内容同质化会反噬流量与信任；且对真正靠产品力复购的餐饮店，把资源压在「标准化IP人设」上可能是资源错配——差评和低复购会更快杀死一个被内容放大的店。

> **以上批判会直接成为下游 skill 的 Boundary (B) 字段来源**

## 4. 应用潜力 (Applicability)

### 可 skill 化的内容
- [ ] 进店理由定位器：15 理由 × 3 维度 → 组合选择 → 内容定位（起点能力）
- [ ] 爆款选题组合器：素材库检索路径 × 八大元素 × 快速六技巧 → 出选题
- [ ] 聊观点脚本写作器：人群/行业选题 + 归纳/对比结构 + 六论据 + 开篇优化
- [ ] 晒过程脚本写作器：四方向 + 火车节模型 + 期待感六技巧
- [ ] 教知识脚本写作器：四型（解决/推荐/揭秘/案例引入）+ 获得感标准
- [ ] 讲故事脚本写作器：三题材 + 桥段库排列组合 + 情绪曲线
- [ ] 作品发布前七问自检
- [ ] 拆片分析法（万能表）
- [ ] 拍摄现场守则：禁忌清单 + IP 情绪保护 + 自然流引导
- [ ] 剪辑十步工作流（粗剪→精剪分级）
- [ ] AI 辅助出选题/写脚本的 prompt 公式
- [ ] 进阶脚本集（追根溯源/帮助弱者/扬我国威/极限测评等，偏 MCN 场景）

### 不适合 skill 化的内容
- 团队分钱机制、大哥带小弟管理观（强个人风格、作者自己都说「不负责任、不科学」）→ 可作案例引用
- 编导求职面试技巧（简历/离职话术）→ 与餐饮老板主场景无关，仅编导个人职业场景适用
- 课堂上大量东北式闲聊、案例叙述冗余部分 → 作能力卡的 example 素材保留

### 预估 skill 数量
**约 9–12 个能力单元**（最终由阶段 1.5 三重验证决定，这里只是粗估）

### 优先级排序 (按"最能赋能餐饮老板"的角度)
1. 进店理由定位器（人人需要、一切内容的起点）
2. 爆款选题组合器（解决"没选题"最高频痛点）
3. 四类脚本写作器（解决"不会写"第二大痛点）
4. 作品七问自检（发布前质量门，成本极低收益高）
5. 期待感钩子设计（流量杠杆）
6. 拍摄现场守则（避免毁素材、毁 IP）
7. 剪辑工作流 / 拆片法 / AI prompt 公式（效率工具）
