# rejected/ — 阶段 1.5 被淘汰候选汇总（审计留痕）

> 规则：未通过三重验证的候选，必须写明是**哪一项**没通过、为什么。
> 「合并」不是淘汰——并入某个 U 单元的能力不计入此处。

## 一、V3 不通过（常识，不需要 skill 承载）

### R01 说人话：讲得浅吸引顾客，太高深吸引同行
- **来源**：03:L325（approx.）
- **判定**：V3 不通过
- **理由**：「要说人话」是任何内容课都会讲的常识，抹掉作者名字后任何一个聪明人都能说出来。
- **去向**：其中""内容深度要跟着目标人群走""的可操作部分已并入 U05 的获得感三标准。

### R02 做 IP 是标准化工程——天下没有一个人做不成 IP
- **来源**：03:L4
- **判定**：V3 不通过
- **理由**：这是讲师的招牌宣言（同时也是阶段 0 批判里标记的**过度承诺**），
  作为情绪动员非常有效，但不产出任何可执行动作；
  做成 skill 会让 agent 在用户明显不适合做 IP 时给出错误鼓励。
- **去向**：保留在 `rejected/`，并在每个能力卡的 B 段作为"不要无条件承诺效果"的反面材料。

### R03 出不来选题要靠搭建素材库
- **来源**：04:L182
- **判定**：V3 不通过
- **理由**："要积累素材"是常识，且没有给出任何检索路径。
- **去向**：具体的检索路径（评论区 / 下拉词 / 热点宝 / 巨量算数 / 跨领域换词）已并入 U02。

### R04 高频、原生、多维（作为整体原则）
- **来源**：01:L76-79
- **判定**：V3 部分不通过
- **理由**：作为口号是常识；但"高频"的定义（每天出现比爆一次更有价值）有反直觉成分 → 保留为
  U01 漏斗诊断中的一个判据，而不独立成能力。

## 二、V1 不通过（只有单一出处，且不可迁移）

### R05 信息流平台三套打法体系（流量经济 / 粉丝经济 / 品牌经济）
- **来源**：仅在 02 逐字稿的机构自我介绍语境中出现一次
- **判定**：V1 不通过
- **理由**：高度依赖该机构自身发展史（2020 年做矩阵、老师分工），无法作为独立方法论外推；
  其可用部分（粉丝经济→品牌经济）已并入 U15 矩阵与团队搭建。

### R06 小而专 vs 大而全选择
- **来源**：03:L100-101 单处
- **判定**：V1 不通过（证据单一）
- **理由**：仅有一个"单品类带货"语境的论据；判断规则（先单品突破再扩品类）
  已并入 U01 的定位路径，不再单列。

### R07 编导求职面试框架（简历撰写 / 自我介绍 / 离职原因 / 防骗）
- **来源**：04:L751-831
- **判定**：V1 通过 / V2 通过 / **V3 勉强**，但**与本次用户选型无关**
- **理由**：这是给"找工作的编导"用的内容，用户选型明确为老板视角（策划与脚本），
  保留他为本次蒸馏范围外。将来若用户转向培训/代招聘场景，可作为新增 capability 引入。
- **去向**：划出蒸馏范围，**不进入 Bundle**（这不是三重验证淘汰，是范围裁剪，故不放进 rejected 计数）。
