# 进阶大制作脚本族群

## 核心要点

> （追根溯源）去产地的原因 → 探寻原料/工艺 → 工厂规模展示、先进设备、技术工艺 →
> 严格质量把控 → 结尾感叹工艺。
> （帮助弱者）交代人物异常行为/事件 → 说出被帮助者当下的困境 →
> 我以让他体面的方式帮助他 → 帮助后的感悟。
> （文化交流）1 选定产品/文化；2 确定真实的交流对象；3 记录体验与理解的变化；
> 4 保留对方自主、真实的表达。

## 方法说明

八类"旗舰级"脚本：追根溯源、探寻传统文化、文化交流、帮助弱者、后记型、
超级访问、大师访问、行业一哥、极限测评（测评四维：成分/效果/耐用/安全）。

它们的共同点是：**需要实地素材、拍摄成本高、产出频次低**，
作用是账号升级与品牌背书，不是日常更新的主力。

每条都有硬前提，选型时先看前提是否符合：
- 追根溯源：必须真有产地/源头可去。
- 探寻传统文化：必须结合本行业相关的文化母体。
- 文化交流：对方必须真实参与并同意入镜，不预设结论，不要求对方配合固定台词。
- 帮助弱者：要让对方体面、不过度帮助、尊重隐私界限。
- 极限测评：要有极限环境与前后对比。

## A1 — 案例

1. **云南屏边苗族自治县追根溯源**：698 亩产地、独特种养方式，
   直接要求把框架套到自己的行业。
2. **帮助弱者的现场复盘**：给困难店主送礼、包场吃饭、随了一万块钱；
   最关键的拍摄纪律是——帮忙过程和讲苦难时都不看镜头，只有最后讲感悟才看镜头。
3. **行业一哥的取材路径**：一个可行的做法是搜"行业一哥一般都说什么"，
   得到三个话题：预测行业未来趋势、盘点过往发展、讲当下困境。

## A2 — 何时触发

品牌升级期、需要一条代表作、要做行业背书或做长内容建立信任时使用。

## E — 执行步骤

1. 按前提筛选题材：先确认硬前提（有没有产地可去、对方是否同意入镜等）是否符合。
2. 写出"看完之后观众会更相信哪一条进店理由"——大制作也必须服务于定位。
3. 按该类脚本的固定段落排出拍摄清单（每一段对应要拍的画面）。
4. 拍摄：实地素材优先，既拍过程也拍结果。
5. 收尾：每类都要回到可验证的落点（工艺细节 / 帮助后的双方感受 / 对方自主的体验变化）。
→ 完成标准：成片能让人说得出"这家店有底气"，而不只是"拍得真好"。

## B — 边界

- 不要在日常更新里使用：成本高、周期长，会拖垮高频原则。
- 帮助弱者类尤其注意伦理：让他体面、不过度帮助、尊重隐私界限，且全程不看镜头。
- 涉及民族、宗教、地域文化时要格外谨慎，避免刻板表达。
- 追根溯源涉及供应链信息时，注意不泄露供货商隐私与自家底价。
- 不符合硬前提就不要硬套；不使用群体身份作为猎奇道具，不编排结果。
