# DIGEST — 实体生意短视频实操方法论精读

> 体系化整理：账号定位 / 爆款选题 / 四类脚本 / 发布自检 / 拍剪执行 / 团队矩阵。
> 本文只保留**经过验证**的部分，浓度高于普通笔记。
> 每个小节末尾标注对应的能力入口，需要深入时有路径。

---

## 一、这套方法到底在讲什么

用一句话说：**做短视频不靠创意，靠工程。**

先把"用户为什么进店"想清楚，再用固定结构批量出选题、填空式写脚本，
用原生、高频的内容把"相信并进店的理由"反复演给本地用户看，最终拿到客资。

这套思路的立论非常直接。开场就是一道选择题：

> a 一个老板 + 200 万投资 + 货盘 + 三个运营 + 两个主播；
> b 农村在家包饺子录成视频的大哥；c 小学文化给村民做屋顶防水的哥们儿；
> d 普通话说不清楚、每天上门安窗帘的大姨。

赚钱的是 BCD。原因不是 BCD 更专业，而是**他们有明确的变现产品，且看起来像真的劳动者**。
另一个广为流传的例子：交了 200 万孵化费，只换来 1300 个粉丝——
"200 万人民币在短视频行业里根本就不叫钱"。

所以整套方法有一个不容商量的顺序：**先定位，后技巧**。
可以把它总结成一张图——左边是变现理由（成交理由），右边是流量技巧。
"每一个选题，首先能变现是成交理由就该拍；至于加不加技巧，加就加一个，不加也没事。"

→ 能力入口：`shortvideo-positioning`

## 二、第一步：找出你的进店理由

「进店理由」这套体系里最核心的词，指的是**用户选择你而不选同行的具体、能被画面证明的原因**。
它被做成了一份封闭清单，共 15 条，分布在三个维度上：

- **产品**：效果好 / 质量好 / 颜值高 / 选择多 / 性价比 / 便利性
- **店铺**：规模大 / 生意好 / 有特色 / 案例多 / 专业强 / 服务好
- **人**：老板好 / 有面子 / 有情怀 / 有担当

规则有三条：
1. 一条内容只主打**一个**理由，"什么都好"等于没有理由；
2. 策划时**至少跨两个维度**组合（产品+人、店铺+产品）；
3. 理由必须在**画面里被展示**，不是口播里被念出来。

然后是三验收，通常叫"水桶型漏斗"：

> 成交理由充足，并且都是真事儿、人家不会质疑，还老出现——OK，
> 你的账号就是一个水桶型漏斗的账号了，你的流量一定会往下漏。

三条缺一不可：**理由充足**（有东西可卖）、**看起来是真事**（原生感）、**天天出现**（高频）。
关于第三条，讲了一个很朴素的道理：你记得楼下卖早点的大姐，
不是因为她做了什么惊天动地的事，**只是因为她每天早上都在**。
百万点赞的爆款第二天就被忘了，高频出现才是被记住的方式。

→ 能力入口：`shortvideo-positioning`

## 三、第二步：爆款选题是乘法，不是灵感

选出理由之后才谈选题。核心公式只有一行：

> 一个选题加上一个爆款元素，就是爆款选题。

八大元素是：**成本 / 人群 / 猎奇 / 最差 / 反差（含对比）/ 怀旧 / 荷尔蒙 / 头牌**。
它们不是内容分类，而是可以叠加在任何选题上的调料——每个元素还能拆成若干**词根**，
比如"花小钱办大事""买完必后悔""千万别""20 年前""XX 同款"。

这套东西为什么跨行业都管用？

> 火这件事儿跟行业没关系……观众就是想看你丢脸嘛，
> 你丢脸观众就给你点赞，就这么点事儿。

标准动作：先一口气列出 15 条平淡但定位正确的普通选题，
再给每条试着挂一个词根，能改成通顺标题的留下（通常只剩 3-5 条），改不动就丢。

三条配套工具同样重要：
- **素材从哪来**：同行/大博主评论区（他们不回复评论但流量大、提问犀利）、
  抖音下拉词与提问词（会/是/怎么/如何/为什么）、热点宝与巨量算数；
- **跨领域换词**：不要只盯同行，"开车四大傻"换成"后厨四大傻"就是你赛道没人出过的新选题；
- **散弹枪原理**：普通选题 + 名人/名校/名企/名牌，直接跨出本行业流量池。

**这里有整套方法唯一的长效陷阱**：词根会被用烂。
当同城三家都在用"千万别 XX"的时候，这套词的唤起能力就失效了，必须换新词根。

→ 能力入口：`shortvideo-topic-generator`

## 四、第三步：四类脚本是填空题

四种内容表达，各自对应一种心智动作，也对应一种账号功能：

| 类型 | 心智动作 | 账号功能 | 结构核心 |
|---|---|---|---|
| 教知识 | 分析 | 展示专业度，涨粉快 | 四型：解题 / 推荐 / 揭秘 / 案例引入 |
| 晒过程 | 行动 | 眼见为实，流量与客资最大 | 火车节模型 + 期待感钩子 |
| 讲故事 | 回忆 | 建立信任，提高溢价 | 桥段库 + 情绪曲线 |
| 聊观点 | 情绪波动 | 拉近关系，聚真粉 | 归纳 / 正反 + 六论据 |

### 教知识：别讲原理，讲动作

四个选题维度是：追求更好 / 解决难题 / 降低成本 / 避免踩坑 / 丰富谈资。
解题型（一切脚本的基础）只有三段：**有画面感的困难场景 → 放大危机 → 给低行动成本的解法**。
解法必须满足"见效快、反馈周期短、行动成本低"，
质量验收叫获得感三标准：**信息多、效果快、料够猛**。

最容易踩的坑是把干货讲成教科书。

> 同样是干减肥的，他俩的播放量、点赞量差这么多——就是你不需要讲知识的原理，
> 你只需要直接告诉大家怎么操作就可以了。

揭秘型值得单独提一句：它既拿流量又立人设。
有一条"阳台窗户报价内幕"的视频，后台全是"怎么找你、怎么联系"的客资。
顾虑"揭秘会影响自家生意"被明确否定了——**观众只会觉得你家不会这么干**。
但边界也很清楚：别把自己卷进灰产，别点到具体可追溯的厂商与个人。

→ 能力入口：`shortvideo-knowledge-script`

### 晒过程：火车往前跑，得靠钩子

结构是"火车节模型"：起因（必加钩子）+ 关键步骤 + 转场 + 经过 + 结果。

> 想在火车上让人从第一节走到第五节？告诉他第五节不但有抽奖还有美女，
> 他就自己抬腿跑过去了——这叫钩子。

钩子的六类零件：**金钱 / 对抗 / 送温暖 / 验证揭秘 / 盲盒 / 荷尔蒙**。
还有三条硬规则：经过控制在 1-3 个且必须服务同一个钩子；
讲述者是"质检员"不是"销售员"；**困难要可衡量，没有困难制造困难也要上**。

配套的一条拍摄观很重要：**帮人的过程不要看镜头**。
做善意的题材时一旦对着镜头，立刻被判定为摆拍——"只有最后讲感悟了，你才可以看镜头"。

同时请忘掉"短视频要短"这件事：

> 能帮平台留住客户的时间越长，流量就越大……判断视频好坏的标准是完播时长、均播时长，
> 并不是点赞数。

→ 能力入口：`shortvideo-process-script`

### 讲故事：桥段是预制的，故事不是编的

核心观点很反直觉：**创新都来自元素的重新排列组合**。
素材来自真实经历，创作者做的是"识别桥段 → 重新排列"。

桥段是四类固定单元：
一轮困境（盲目自信 / 家门不幸 / 天灾人祸）→ 一轮转机（通关密码 / 至亲寄托 / 贵人相助 / 天赋异禀 / 意外之喜）
→ 二轮困境（恶霸欺压 / 过河拆桥 / 至亲背叛 / 强权干涉）→ 二轮转机（因祸得福 / 贵人相助 / 破釜沉舟）
→ 感悟 → 知识点。

唯一的量化规则叫情绪曲线：**第二轮痛点必须高于第一轮，第二轮爽点也必须高于第一轮**，
否则故事走平。跨行业最省力的版本是"歌颂他人"——夸自己不容易火，夸别人才容易火。
有一家店拍跟了自己多年的老员工（后来给她买电动车），拿了 1.2 万赞。

→ 能力入口：`shortvideo-story-script`

### 聊观点：先决定替谁说话

观点类内容在这个体系里只有一个功能：**拉近关系，聚真粉**。所以：

> 很多人会不会骂我，跟我观点不一致的人会不会骂我？不会……你们观点之所以能火，
> 就是因为吸引的是跟你观点一致的人。

选题有两条发生器：
**行业选题** = 行业/产品/从业者/消费者 × 误解/批判/支持/建议；
**人群选题** = 写作对象（家庭/工作/社会关系）× 一个冲突事件。
两者的分工是：人群拿大流量，行业拿精准客资，两种都要拍。

论据有六种集成块：权衡利弊、无奈之举、不同视角、维度升级（这四个常用）、
人身攻击、倒打一耙（这两个慎用）。
底层心法是：**给观众想做但不好意思做的事找理由，给不想做或没做成的事找借口。**

开篇有一句可以直接用的规则：**疑问句弱、肯定句中、否定句最强**
（"公寓购买分析" → "千万不要买公寓"）。60 分选题加开篇优化，就是 90 分选题。

→ 能力入口：`shortvideo-opinion-script`

## 五、发布前的最后一道门

不管写了什么，发出去之前跑七问：

1. 有用、有趣、有共鸣吗？（信息有效）
2. 跟精准粉丝关联度高吗？（信息关联）
3. 会不会太枯燥？（内容趣味）
4. 用户容易学会吗？（行动成本）
5. 是用户频繁发生的难题吗？（发生频次）
6. 能不能可持续延伸？（内容持续）
7. 能不能落地解决问题？（内容价值）

判定只有三档：**通过 / 修改后通过 / 暂不发布**。
第三档是有意义的——很多内容不该发出去，重做一条通常比发出去更划算。
再叠加成片三要点：结构完整有中心思想、语言逻辑通顺画面流畅、**爆点前置**。

另外记住：数据回收后的判断标准是后台的**均播时长**，不是点赞数。
一个视频能让粉丝平均看三分钟，他进你直播间就更可能听完整套成交。

→ 能力入口：`shortvideo-script-selfcheck`

## 六、陷阱清单（这部分比上面更重要）

1. **先搭团队、备货盘、投钱，再想拍什么** —— 顺序倒了就有播放无成交。200 万赔光的是这种。
2. **外包孵化 / 代运营** —— 200 万换来 1300 粉的真实案。合同指标若只是"发布条数/涨粉"，一定不对。
3. **被拍成"假人"** —— 代运营让你穿西装、上相机、端着说话。这类视频有技巧有流量，
   但观众看得出是假的，账号不变现。小杨哥、几十亿资金盘的从业者都用手机拍。
4. **本地号一开头报地名** —— 把本来全网可用的选题锁死在本地流量池。
   正确做法是先拿人群流量，再用行业选题收精准。
5. **生打广告** —— "广告别生打，中间加钩子"。没有钩子就没有停留。
6. **迷信 7 秒/15 秒** —— 平台按留住时长给流量。
7. **只搜一个平台就开拍** —— 全网同质信息，拿不到"信息多"。
8. **拍摄现场五不做** —— 不批评 IP 情绪、不要求完全背稿、不打断、不谎称没录上、不说悄悄话。
   前三条摧毁松弛感，第四条是欺骗。
9. **剪辑红线** —— 不要吞字、不用系统字体、白字加阴影、贴纸只用四类、精剪切勿花哨。
10. **荷尔蒙元素的平台风险** —— 实践中也有"发了账号封了"的教训。大多数实体生意用不上。
11. **词根用烂** —— 同赛道都在用同一句式时，有效性归零。
12. **AI 开着推理跑写好的指令** —— 会在信息不足处自行脑补，输出不可控。

## 七、用好这套方法的四个原则

- **以经营结果为目标**：播放量和粉丝数用于观察内容，有效咨询、到店、成交与复购用于验收业务。
- **以真实业务为证据**：把产品、服务、价格、交付和客户反馈变成画面，不用空洞口号代替真实优势。
- **以自有素材做差异**：可以复用结构，但人物、细节、案例、语气和证据必须来自自己的生意。
- **以连续测试做迭代**：按品类、客单价、地域和客户阶段分组复盘，把有效表达沉淀成自己的内容资产。

## 八、怎么用起来

七个可独立调用的入口，外加一个总路由：

| 场景 | 入口 |
|---|---|
| 不知道自己有什么可拍 / 有播放无客人 | `shortvideo-positioning` |
| 知道优势，缺具体选题 / 标题不够勾人 | `shortvideo-topic-generator` |
| 要表达态度、借热点表态 | `shortvideo-opinion-script` |
| 要拍进货/备餐/服务/装修这类过程 | `shortvideo-process-script` |
| 要讲干货、用专业度涨粉 | `shortvideo-knowledge-script` |
| 要讲创业经历、夸员工、做店庆 | `shortvideo-story-script` |
| 写完了要不要发、数据差在哪 | `shortvideo-script-selfcheck` |
| 不确定走哪个 / 想查术语与细节 | `shortvideo-playbook`（路由入口） |

路由入口内还保留了 8 张补充能力卡：AI 出选题提示词公式、拍摄呈现场域、剪辑十步工作流、
自然流拍摄引导、拆片万能表、进阶大制作脚本族群、IP 定位问卷与账号策划表、矩阵与团队搭建。

推荐的使用顺序：

1. 先跑 `shortvideo-positioning`，把进店理由和三验收做实；
2. 用 `shortvideo-topic-generator` 一次性攒两周选题；
3. 按选题类型分别交给四类脚本能力写稿；
4. 发布前一律过 `shortvideo-script-selfcheck`；
5. 数据回来后如果单条差 → 自检；如果账号持续差 → 回到定位层。

> 本 Bundle 附带 darwin 兼容的触发评测（`tests/test-prompts.json`），
> 可以用 darwin-skill 做持续进化。
