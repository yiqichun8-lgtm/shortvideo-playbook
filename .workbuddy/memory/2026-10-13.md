   `verified.yaml` 必须有 `bundle_id / book{title} / entry{name,description,core_principles,out_of_scope,stop_conditions} / router_entry / promotion_budget / capabilities[]`；
   capability 字段必须含 `capability_id / revision / status / slug / title / importance / intents / keywords / card / frontmatter{description,tags} / promotion{destination}`；
   `book/overview.md`、`book/glossary.md` 放 Bundle 目录才会被拷进 references。

   写完候选/卡片后必须 grep 一遍这些异常串再回原文校正引文——证据准确性是下游卡片的基础。
4. 引文必须回原文用行号核对，不要凭印象写 quote。已发现并修正多处失真。
