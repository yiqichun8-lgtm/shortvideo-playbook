# AI 出选题 / 写文案提示词公式

## 核心要点

> （人群选题）我的身份是什么什么什么，这个是大家的身份，身份说的越具体越好……
> 我的写作对象是谁……这个话术给他之后，他就会给你出选题。

> （行业选题）我是一名做了十年的装修设计师，对你们是什么身份写明白，
> 然后我的写作对象……写清楚预算、写清楚高净值人群，哪怕月收入都可以。

> 如果用 deepseek 会出现这个问题，你们就把（推理）关了——我们的提示词都不需要它推理……
> 推理的结果非常不可控。

## 方法说明

把 AI 当作业流水线的加速器，用三层 prompt：**出选题层 → 写文案层 → 加爆款元素层**。

第一层的关键是"身份具体化"：只说"我是开饭店的"会得到通用垃圾，
说"我是一家 120 平、客单价 60 元、主打本地家常味的社区川菜馆老板，
目标是 3 公里内 25-40 岁的上班族"才能得到可用选题。
第二层是把脚本结构或论据类型的清单直接喂进去，让它按结构写，而不是自由发挥。
第三层是让它把已出选题逐个挂载爆款词根。

操作上最重要也最反直觉的一条：**关掉推理功能**。提示词已经足够具体时，
推理会在信息不足处自行脑补，反而产出不可控的内容。

## A1 — 案例

1. **重复两次出现的装修设计师句式**：同一套句式被重复给出两次，
   要点是"直接复制给他们就好了"，说明这是标准化模板而非即兴发挥。
2. **用 AI 做拆片智能体失败**：产出第一秒是什么、第二秒是什么的逐秒描述，
   关键自问："这个片子哪火、我怎么借鉴"——说明 prompt 必须指定输出形态。
3. **猎奇类选题的 AI 句式**："我的行业有什么让人惊掉下巴的信息"
   一句即可让 AI 产出可用素材。

## A2 — 何时触发

需要一份可以拿去别处（豆包 / DeepSeek / 其他 AI）使用的 prompt；
或者想在别的工具里复用这套流程时。若由本 pack 直接执行，优先走对应脚本能力。

## E — 执行步骤

1. 写身份句：店铺面积 / 品类 / 客单价 / 团队规模 / 经营年限，越具体越好。
2. 写对象句：目标客户的年龄、距离、收入或预算、消费场景。
3. 提出需求：出 N 条选题，指定维度（行业/产品/消费者/误解/批判/支持/意见）。
4. 关闭推理功能（如 DeepSeek 的深度思考），保持指令驱动。
5. 选定第 N 条后，把对应的脚本结构/论据清单追加进去，让它写成文案。
6. 最后一步：让它给每条选题加一个爆款词根，挑通顺的留下。

→ 完成标准：每一步的输出都能被人直接读取，不需要人工"翻译成人话"。

## B — 边界

- 不要让 AI 替你做商业判断：身份与进店理由必须由人给定，AI 只做扩展。
- 涉及行业事实的知识点必须人工核查，AI 生成的知识内容可能失真。
- 关推理 ≠ 不要追问：需要更细时追加具体条件，而不是打开推理让它自由发挥。
