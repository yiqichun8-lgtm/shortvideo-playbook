# IP 定位问卷与账号策划表

## 核心要点

> （IP 定位表）基本信息 / IP 喜好 / 经历（重点描述）/ 工作。
> 了解 IP 本人：浏览近半年最火的 10 条视频；了解 IP 行业：掌握 15 个行业名词或入门知识、
> 搜索 5 个行业有关的热门事件。

> （运营策划表）产品端：产品 / 定价区间 / 人群 / 卖点 / 市场需求 / 技术壁垒 / 商家；
> 流量端：线上 / 线下 / 转化率 / 成交成本；交付端：边际成本 / 售后 / 服务 / 风险。

## 方法说明

这是**接手一个账号前的 intake 流程**，回答"我还什么都不知道时先问什么"。

两段式：先用运营策划表把生意本身搞清楚（产品端 / 流量端 / 交付端），
再用 IP 定位问卷把人搞清楚（基本信息、喜好、经历、工作）。
其中"经历"部分才是脚本素材的真正来源——尤其要认真对待的几题：
上一次哭是什么时候、最开心是什么时候、近十年高光时刻、创业踩过的坑、
怎么赚到第一桶金、至今最大的成就。

另外还有一条硬性的准备量：进场前必须看完近半年最火的 10 条视频、
掌握 15 个行业名词、搜到 5 个行业热门事件。没做这三点，就不具备做内容的资格。

## A1 — 案例

1. **IP 问卷里的关键题**：最后一次哭、最开心、高光时刻、
   踩过的坑、第一桶金、最大成就——对应到讲故事脚本的困境与转机桥段。
2. **服装批发视频里的密度**：视频里出现的具体数据（单款单色五件起拿、
   上装下装 3:1）来自对行业的了解，而不是编辑现场的灵机一动。
3. **偷师系列的出发点**：偷师系列的出发点来自一条用户评论——
   intake 的素材也可以来自评论区而不是问卷。

## A2 — 何时触发

接一个新客户/新账号；给自家账号做全面盘点；或为讲故事能力收集素材。

## E — 执行步骤

1. 填产品端：卖什么、价格带、目标人群、与同行的差别、市场需求、技术壁垒。
2. 填流量端：线上线下怎么获客、转化率、成交成本。
3. 填交付端：边际成本、售后、服务、风险。
4. 走 IP 问卷：基本信息 → 喜好 → 经历（重点）→ 工作，全程录音。
5. 做功课：近半年最火 10 条视频 + 15 个行业名词 + 5 个行业热门事件。
6. 从问卷里标记可用的进店理由与故事桥段，交给「进店理由与账号定位」与「讲故事脚本」。
→ 完成标准：三端表无一格空着；问卷里至少标出 3 条可用进店理由和 2 段可用经历。

## B — 边界

- 敏感题（收入、家庭关系、婚姻状况）要说明用意，得到同意再问；
  涉及隐私的内容如不拍就不要记录。
- 不要一次性问完所有问题：建议分两三次，避免答题疲劳导致答案敷衍。
- 这份问卷服务于内容，**不服务于合同**：涉及到数字的内部信息不合适公开传播。
- 不要把"攻略/模板"当成理解行业：15 个名词的功课量是硬指标。
