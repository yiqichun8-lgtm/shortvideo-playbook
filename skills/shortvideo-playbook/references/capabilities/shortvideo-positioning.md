# 进店理由与账号定位

## 核心要点

> 进店理由从三个维度寻找：产品、店铺、人。策划拍摄内容时，尽量选择两个及以上维度组合呈现。

> 成交理由充足、内容真实、且能高频出现时，账号才具备把关注转成咨询与成交的基础。

## 方法说明

这套方法回答一个前置问题：**用户为什么选你而不选同行**。它把答案做成了一张封闭清单——
15 条进店理由，分布在产品 / 店铺 / 人三个维度上。

操作上是三步：先在清单里勾出你真正站得住的 2-3 条（每条内容只主打一个，多个内容之间可用不同组合）；
接着用"水桶型漏斗"做验收——成交理由是否充足、看起来是不是真事、能不能持续高频出现；
三条都成立，才谈得上后面加爆款元素和写脚本。

它的关键约束力在于**顺序**：先定成交理由，再选内容方向。
绝大多数账号做不起来，是因为把这个顺序倒过来了——先有团队、先有流量焦虑、先想拍什么，
才回头问自己"我到底靠什么让人来"。

## A1 — 案例

1. **ABCD 定位选择题**：一个老板 + 200 万投资 + 货盘 + 三个运营 + 两个主播（A），
   对比农村包饺子录视频的大哥、小学文化做屋顶防水的哥们、普通话说不清上门安窗帘的大姨（BCD）。
   赚到钱的是 BCD。结论：工具和投资不构成进店理由，可交付的产品加上可信的人才是。
2. **200 万孵化费只做出 1300 个粉丝**：钱换不来正确的商业定位，
   连夜追回 100 万。
3. **单品类带货先聚焦**：李佳琦从单品类起 IP；
   老板普遍担心"做死在单品上"，答案是：不会。——说明聚焦一条进店理由不等于被锁死。

## A2 — 何时触发

**典型场景**
- 有实体生意（门店/工厂/服务商）准备做短视频、准备做账号，或做了很久没客资
- 老账号有播放有涨粉但没有咨询，需要诊断原因
- 不知道该拍什么、多人给的建议互相矛盾，需要一个判断基准

**语言信号**："我该拍什么" "我们账号怎么定位" "为什么有人看没人来"
"我家到底有什么可拍的" "帮我看看这账号问题在哪" / account positioning, what should I post

**与相邻能力的区分**
- 只缺具体选题（已经想清楚自己的优势）→ 走「爆款选题组合器」
- 已经有一条想拍的内容要落成脚本 → 走四类脚本能力之一
- 想要流量技巧但没做过定位 → **必须先走本能力**，否则技巧无效

## E — 执行步骤

1. **列事实**：把这门生意的真实情况列出来（产品 / 价格带 / 位置 / 团队 / 老板本人 / 老客来源），
   只写能被画面证明的事，不写形容词。→ 完成标准：至少 10 条事实。
2. **逐条比对 15 条进店理由**（效果好 / 质量好 / 性价比 / 选择多 / 便利性 / 颜值高 / 有特色 /
   规模大 / 生意好 / 案例多 / 专业强 / 服务好 / 老板好 / 有面子 / 成本低），
   勾出真正成立的。→ 完成标准：勾选项 ≤3，且每项都能说出"用什么画面证明"。
3. **选维度组合**：要求至少跨两个维度（产品+人 / 店铺+产品），避免全落在同一维度。
   → 完成标准：写出组合，如"效果好（产品）+ 老板好（人）"。
4. **漏斗验收**：逐条问自己三条——成交理由充足吗？看起来是真事吗？能不能每周都出现？
   → 完成标准：三问全部为"是"才算定位通过；否则回到第 2 步换理由。
5. **定客户阶段与内容任务**：先判断对方是还没意识到问题、正在比较方案，还是已经准备购买；
   再选择本条的任务：建立理念 / 增加信任 / 给出购买理由 / 发布行动通知。
6. **定内容表达**：按四类分工选择主打类型——教知识（展示专业）/ 晒过程（给出可见证据）/
   讲故事（建立信任）/ 聊观点（识别同频人群）。
   → 完成标准：定下"主打 X，辅以 Y"。

## B — 边界

- **不要在多轴上同时发力**：一条内容主打一个理由；"什么都好"等于没有理由。
- **不要把进店理由当广告语使用**：它必须在画面里被展示，不是口播里被念出。
- **本地号不要默认在开头报地名**：若选题本身能吸引更广人群，过早加地域会缩小测试面；
  但对强地域需求、活动通知或到店路线类内容，地名可以直接提高筛选效率。
- **这条方法只在有真实产品/服务时成立**：没有任何成交理由时就做账号，
  是本体系明确认为不该开始的状态（先把生意本身理顺）。
- **方法的筛选偏好**：这套清单把"能不能被拍出来"当筛选标准，
  因此会低估难以视觉化的优势（如供应链、后台管理、长期口碑）。使用时补一句：
  拍不出来的优势，用"案例多""专业强"这类可讲的形式间接呈现。
- **不要承诺效果**：定位正确只提高变现概率，不保证结果。
