# GLOSSARY — 实体生意短视频方法论 · 术语词典

> 全套方法论的共享术语表。定义取自本方法论的实际用法，不用字典义。

| 术语 | 本方法论中的定义 | 与常识用法的差异 |
|---|---|---|
| 进店理由 / 成交理由 | "进店理由从三个维度寻找：产品、店铺、人。……说 XXX 好就主要体现什么好。" | ≠「卖点/差异化」（那是给同行看的定位）<br>    ≠「广告语」（那是文案，不是理由）<br>    = 用户选择你而不选同行的具体、可被画面证明的原因；共 15 条封闭枚举，<br>      一条内容只主打一个，多条内容之间用不同组合。 |
| 水桶型漏斗 | "成交理由充足，并且都是真事儿、人家不会质疑，还老出现——OK，     你的账号就是一个水桶型漏斗的账号了，你的流量一定会往下漏，一定会变现好。" | ≠「漏斗」（营销漏斗讲的是转化层级）<br>    = 一个判别式：成交理由充足 + 原生感 + 高频出现，三者同时成立即"定位正确"，<br>      流量会自然往下漏成成交。没成立之前谈技巧没有意义。 |
| 原生感 / 原生 | "越自然越好：说人话，不夹，不装，不开美颜，不用花哨的分镜头，少用画外音。" | ≠「画质好」「制作精良」<br>    = 观众相信视频里的这个人就是生活中的这个人；<br>      假 = 穿不属于自己的衣服、用相机、端着说话、用不属于自己的语气。<br>      注意：不是粗糙，而是"人格一致"。 |
| 三有原则 | "内容被喜爱的三有原则：有用处、有兴趣、有共鸣。"     有用处→教程类/推荐类；有兴趣→美好类/炫技类/恶搞类；有共鸣→情感类/励志类/吐槽类。 | ≠「好内容」的泛泛标准<br>    = 选题时的三选一过滤器：一条内容必须明确命中其中至少一项，否则不进入脚本环节。 |
| 八大爆款元素 | "成本的、人群的、奇葩的、最差的、反差的、怀旧的、荷尔蒙的、头牌的。     一个选题加上一个爆款元素，就是爆款选题。" | ≠ 内容类型（它们不是赛道、不是脚本类型）<br>    ≠ 选题本身（它们是叠加在选题上的"调料"）<br>    = 八个人类共通的观看动机；行业无关，"火这件事跟行业没关系"。<br>      注：反差与对比本可拆成两个，为便于记忆合并成"八大"。 |
| 爆款词根 | "（把这八个爆款元素拆成 30 多个词根），把这个'花小钱办大事儿'这个人类爱看的     爆款词根往 AI 里一输就搞定了。" | ≠ 爆款元素（元素是八个大类）<br>    = 元素的具体词汇化表达，可直接套进标题：<br>      "花小钱办大事/最省时间/最省力气/最省钱"（成本）、<br>      "买完必后悔/用了必后悔/9块9/最惨的"（最差）、<br>      "千万不要/建议不要"（否定句式）、"20年前的/当年/经典的/古代"（怀旧）、<br>      "同款/名校/名企/最贵的/最有面子的"（头牌）。 |
| 火车节模型 | "起因（必须加钩子）→ 关键步骤 → 转场 → 经过 → 转场 → 关键步骤 → 继续经过与转场 → 结果。     想在火车上让人从第一节走到第五节？告诉他第五节有抽奖还有美女，他就自己抬腿跑过去了——     这叫钩子。" | ≠ 一般叙事结构（起因经过结果）<br>    = 晒过程专用：每一节车厢之间都要有钩子驱动，关键步骤里埋入要展示的专业点，<br>      结果处才是客资转化点。经过控制在 1-3 个，多个经过要服务同一个钩子。 |
| 钩子 | "广告别生打，中间加钩子。……（钩子）第五节车厢不但有抽奖还有美女。" | ≠「悬念标题」<br>    = 让观众再走一节车厢的具体理由，可以是金钱/对抗/送温暖/验证揭秘/盲盒/荷尔蒙六类；<br>      出现在起因（必加）、也出现在段落之间（少而精）。 |
| 期待感 | "（钩子）用三个字去总结：期待感。让观众永远充满着期待感，我就愿意看下去。" | ≠「氛围感」<br>    = 可勾选的六类钩子清单（金钱/对抗/送温暖/验证揭秘/盲盒/荷尔蒙）；<br>      晒过程的核心指标就是让观众从头到尾对未来有预期。 |
| 桥段 | "经典桥段：一轮困境（盲目自信/家门不幸/天灾人祸）、一轮转机（通关密码/至亲寄托/贵人相助/     天赋异禀/意外之喜）、二轮困境（恶霸欺压/过河拆桥/至亲背叛/强权干涉）、     二轮转机（因祸得福/贵人相助/破釜沉舟）。……创新都来自元素的重新排列组合。" | ≠「剧情桥段」的泛称<br>    = 固定的、可枚举的叙事单元库；创作动作是"识别 → 重新排列组合"，<br>      不是"发明新故事"。成功案例型中"贵人"必须是讲述者本人。 |
| 情绪曲线 / 难点升级 | "2、一轮困境（背景简单带入，快进主题）；4、二轮困境（二轮痛点要高于一轮）；     5、二轮转机（二轮爽点要高于一轮）。" | ≠「要有情绪起伏」<br>    = 可量化规则：第二轮的痛点和爽点必须高于第一轮，否则情绪曲线走平。 |
| 六论据 | "权衡利弊（不这么做会失去什么，这么做会得到什么）、无奈之举（该懂的该做的都尽力了，     但我没有办法）、不同视角（当事人怎么想、旁观者怎么想）、维度升级（从历史时间线或     未来社会影响看问题）、人身攻击（对当事人的外貌、品行或智力评头论足）、     倒打一耙（不讨论实际事实，只抒发心情）。" | ≠「论据」（一般意义上的证明材料）<br>    = 六种固定的说服路径（零件库），一个视频通常只用一个，长文案可用两个；<br>      常用组合是权衡利弊 + 维度升级。底层心法：给观众"想做但不好意思做的事"找理由，<br>      给"不想做或没做成的事"找借口。 |
| 质检员还是销售员 | "讲述者是'质检员'还是'销售员'？（自检问题）" | ≠ 一个职位<br>    = 晒过程时的讲述姿态自检：你是在中立地展示/检验这个过程（质检员），<br>      还是在推销（销售员）。前者留人且不引起防备，后者观众立刻关闭。 |
| 获得感 | "推荐内容的获得感标准：效果好、料够猛、信息多。" | ≠「有价值」的笼统评价<br>    = 三条可对照的自检项：解法见效快/反馈周期短/行动成本低，<br>      内容密度高（一次给到 5-8 条）。 |
| 情绪波点 | 观点类内容让观众进入特定人群的立场与情绪。 | 写观点前先决定"替谁说话"，再选择论据。 |
| 置身事外 | 从"我在做事"切换到"我在讲述和审视这件事"的视角。 | 在过程视频中留出解说者位，用于补充背景、设置悬念和连接环节。 |
| 均播时长 / 完播时长 | "怎么判断一个视频好不好？记住：完播时长，并不是点赞数。     后台可以看到一个均播的时长，均播时长拉的越高……进入直播间看你的视频更有耐心听成交。" | ≠ 完播率百分比（很多教程把它当成核心指标）<br>    = 后台的"平均播放时长"绝对值；它决定粉丝对你的耐心额度，决定直播间成交能力。 |
| 矩阵 | "矩阵的意义呢，其实是从粉丝经济到品牌经济一个过渡……可不是多赚点儿钱的事儿。" | ≠「多开几个号多份收益」<br>    = 让多个 IP 的观众反复看到同一个品牌名，形成品牌资产沉淀。 |
| 拆片 | "（拆片万能表）内容类型/脚本结构/拍摄角度/出镜人物/呈现形式/出场方式/剪辑方式。" | ≠「拉片」（逐秒描述画面，本方法论明确否定了这种做法：<br>      "把一个片子拆成第一秒是什么、第二秒是什么……那我用它干嘛呀？"）<br>    = 输出"这条为什么火 + 我怎么借鉴"的结构化分析。 |
| 散弹枪原理 | "散弹枪原理：扩大流量。普通选题 + 明星/名企/名人/名校 = 爆款选题。" | ≠ 泛泛地"蹭热点"<br>    = 借一个更大的已知载体来突破本行业流量池的具体加法操作，是"头牌"元素的别名用法。 |
| 自然流 | "（拍摄引导）前期破冰/中期引导/后期鼓励……让出镜者拍得更自然的好处：老板喜欢+流量大。" | ≠「自然流量」（区别于付费流量的那个"自然流量"）<br>    = 一种拍摄方式：不背稿、现场提问引导、当场出情绪，成片显得没被设计过。<br>    这是整套方法论里最容易被混淆的术语之一。 |
| 英雄时刻 | "平凡英雄的英雄时刻：自己解决问题、敢作敢当、随手帮助、坚守原则、仗义扶弱、     积极面对、及时回怼。" | ≠「高光时刻」（那是结果）<br>    = 七种可被识别的高光行为类型，用于在素材里标记"这里是不是英雄时刻"。 |
