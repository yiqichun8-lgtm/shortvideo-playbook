# 讲故事脚本

## 核心要点

> 三个内容方向：小有成就（讲自己已经达成的成就）、成功案例（讲他人的成就）、
> 平凡英雄（体现英雄时刻）。

> （小有成就型基础结构）已达成的成就 → 第一轮困境 → 第一轮转机 → 第二轮困境 →
> 第二轮转机 → 目标带来的感悟 → 知识点。
> （第一轮困境）盲目自信、家门不幸、天灾人祸；（第二轮困境）恶霸欺压、过河拆桥、
> 至亲背叛、强权干涉。

> 创新都来自元素的重新排列组合。

## 方法说明

讲故事在本体系里的账号功能是**建立信任与提高溢价**：当客户觉得"我了解这个人"，
价格就不再是唯一变量。

它的核心洞察是：**故事不是凭空编出来的，是从经历里识别桥段再重排出来的**。
素材来自真实经历（可以先用微信语音口述），然后把它们识别为固定的桥段单元
（一轮困境：盲目自信 / 家门不幸 / 天灾人祸；一轮转机：通关密码 / 至亲寄托 /
贵人相助 / 天赋异禀 / 意外之喜；二轮困境：恶霸欺压 / 过河拆桥 / 至亲背叛 / 强权干涉；
二轮转机：因祸得福 / 贵人相助 / 破釜沉舟）。

硬规则叫**情绪曲线**：第二轮的痛点和爽点都必须高于第一轮，否则故事走平。
成功案例型的变化是主体变成他人、且第一轮转机中的"贵人"必须是讲述者本人，
同时必须写对方自己的努力，不能只写你帮了他。

结尾负责情绪落点：批判不爽的事 / 回怼解气 / 提炼感悟 / 正向呼吁。

## A1 — 案例

1. **"小豆海棠"拍娘娘（1.2 万赞）**：乐山一家店拍跟了自己多年的老员工，
   后又给她买电动车——属于平凡英雄 / 歌颂他人型，同城顾客自发到店。
2. **"零零后小姑娘一个月花 500 块"**：同一素材池的另一个样本，10 万赞。
3. **成功案例型的要求**：成功案例型要求"贵人就是我自己"
   并且"不能只写你对他的帮助，还要有他的努力"——这是这类脚本最容易漏掉的一步。

## A2 — 何时触发

**典型场景**
- 想让人了解老板/店的来历，提高溢价承受力
- 想拍自己的创业经历、踩过的坑
- 想夸某个员工、某个客户、某个帮助过自己的人
- 逢店庆、纪念日、转危机为机的节点

**语言信号**："讲讲我的故事" "想拍个关于店怎么开起来的视频" "这条经历怎么讲才好看"
/ brand story, founder story, why I started

**与相邻能力的区分**
- 是教别人做事 → 「教知识脚本」
- 是展示正在做的事 → 「晒过程脚本」
- 是表达态度 → 「聊观点脚本」
- 只是组织不了素材 → 先做 IP 深度采访问卷（路由卡）

## E — 执行步骤

1. **定题材**：小有成就 / 成功案例 / 平凡英雄 三选一。
   → 完成标准：说出题材，并确认主角是谁（自己 / 他人 / 此刻的 hero 行为）。
2. **口述素材**：用录音先讲一遍，不要先想结构。
   → 完成标准：得到一段 5 分钟以上的口语素材。
3. **识别桥段**：在素材里标注困境与转机分别对应哪个桥段类型；素材不足就用近类桥段补。
   → 完成标准：至少识别出两个困境 + 两个转机。
4. **重排并保证曲线上升**：第二轮痛点 > 第一轮痛点，第二轮爽点 > 第一轮爽点。
   → 完成标准：把更痛的那轮放在后面，能明确说出"第二轮更痛在哪"。
5. **写结尾**：批判 / 回怼 / 感悟 / 正向呼吁四选一。
   → 完成标准：结尾把"我"和"观众"联系起来，而不是停留在自我抒情。
6. **提炼知识点**：最后补一句"所以……"，让故事不只是回忆。
   → 完成标准：能写出一句可被总结的道理。
7. **自检**：见「发布前自检」。

## B — 边界

- **不要编桥段**：本质是"识别 + 重排"，编出来的不合桥段逻辑，观众能感觉到。
- **成功案例型必须写对方的努力**：只写你对他的帮助会显得自我表彰，
  且会伤害被讲者的自尊。
- **帮助/行善类过程不要看镜头**：真实性的唯一证明是"忘记镜头存在"。
- **不要把苦难以猎奇方式消费**：特别是涉及员工、弱势群体时，
  必须尊重隐私与界限，且"让他体面"（见进阶脚本卡的边界）。
- **不要一次塞多个主题**：一个故事一条主线（取得信任 / 展示某个品质），否则情绪线断裂。
- **注意这类内容的转化路径较长**：讲故事提高的是溢价与信任，不适合作为直接促销内容。
